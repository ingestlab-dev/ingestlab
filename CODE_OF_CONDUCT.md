# Code of Conduct

## Our standard

We want IngestLab to be a welcoming project for everyone. Participants are
expected to be respectful, constructive, and open to different backgrounds
and experiences.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sexualized language or imagery, doxxing, and publishing private information
without permission.

## Enforcement

Report unacceptable behavior privately through the repository's GitHub contact
options. Project maintainers may remove comments, close issues or pull
requests, restrict participation, or take other action they consider
appropriate.

## Scope

This code of conduct applies to the repository, its issue tracker, pull
requests, discussions, and project-related events or communication.
